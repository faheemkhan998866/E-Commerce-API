# E-Commerce-API
E-Commerce API

A backend e-commerce API built with Python, FastAPI and MongoDB.

Features:
- Product creation
- Product listing
- Product update
- Product deletion
- Category filtering
- User registration
- User login
- Password hashing
- HTML frontend

Technologies:
- Python
- FastAPI
- MongoDB
- PyMongo
- Pydantic
- HTML
- JavaScript

How to run:
1. Install requirements
2. Start MongoDB
3. Run FastAPI with Uvicorn
4. Open the HTML page
